마비노기 경매장 공유 시세 피드

마비노기(PC) 도우미 앱(물물교환 도우미, 아르바이트 도우미, 던전 통행증 트래커)이 함께 쓰는 경매장 시세 데이터입니다. 서버가 Nexon Open API 경매장 정보를 정해진 주기로 한 번만 조회해 JSON으로 게시하고, 각 앱은 API를 직접 호출하지 않고 이 파일을 읽습니다.

데이터: prices.json — 형식 {updated, prices: {아이템명: {min, count, t}}} (min = 개당 최저가, count = 매물 수량)

소스: github.com/forgetwulf-oss/mabi-prices · Data based on NEXON Open API.
